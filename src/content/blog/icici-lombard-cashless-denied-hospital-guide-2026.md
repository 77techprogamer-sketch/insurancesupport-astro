## ICICI Lombard Cashless Flow — Where It Breaks

```
Patient Admission
       ↓
Hospital Sends Pre-Auth to TPA (Paramount/MDIndia/HealthIndia)
       ↓
TPA Reviews → APPROVES / QUERIES / REJECTS
       ↓
If QUERY: Hospital responds → Re-review (2-6 hours)
       ↓
If REJECT: Denial code issued → Patient pays → Reimbursement route
```

**Break points**: Incomplete documents, pre-existing disease allegation, package rate dispute, hospital not in network, ICD code mismatch.

## The 4-Hour Cashless Rescue Protocol

### Hour 0-1: Immediate Action at Hospital

**At Admission Desk**:
1. **Demand written denial** with code (verbal "not approved" = useless)
2. **Get TPA name** (Paramount/MDIndia/HealthIndia)
3. **Photograph** pre-auth form + denial slip
4. **Ask for "Cashless Coordinator"** by name

**Call ICICI Lombard Immediately**:
```
Cashless Helpline: 1800-2666 (24×7)
Email: cashless@icicilombard.com
Escalation: nodal.grievance@icicilombard.com
```
Give: Policy no, patient name, hospital, denial code, TPA name.

### Hour 1-2: Hospital-Level Escalation

**Demand from Hospital**:
- Re-submission with complete docs (if DOC-02)
- Doctor's detailed justification letter (if PED-01/ICD-05)
- Package rate breakdown vs IRDAI CGHS rates (if PKG-03)
- Network status proof / emergency certificate (if NET-04)

**Hospital Must**: Re-submit within **2 hours** of query. Track via TPA portal.

### Hour 2-3: TPA Direct Escalation

| TPA | Escalation Email | Escalation Phone | Nodal Officer |
|-----|------------------|------------------|---------------|
| **Paramount** | escalation@paramounttpa.com | 1800-102-1234 | Mr. Rajesh (Bangalore) |
| **MDIndia** | grievances@mdindiaonline.com | 1800-425-1234 | Ms. Sunita (South India) |
| **HealthIndia** | complaints@healthindiatpa.com | 1800-300-1234 | Mr. Prakash (Karnataka) |

**Email Template**:
```
Subject: URGENT — Cashless Denial Re-review — Policy: [XXXXXX] Patient: [Name] Hospital: [Name] TPA: [Name]

Denial Code: [Code]
Pre-Auth Ref: [Number]
Date of Admission: [Date]
Sum Insured: ₹[Amount]
Claim Amount: ₹[Amount]

Details: [2-3 lines on why denial is incorrect]
Attachments: Denial slip, doctor letter, policy schedule, ID proofs

Request: Re-review and approval within 4 hours per IRDAI 30-day cashless regulation.
Contact: [Your mobile], [Email]
```

### Hour 3-4: IRDAI / Regulatory Escalation

If TPA doesn't revert in 4 hours:
1. **File IGMS complaint**: https://igms.irda.gov.in
2. **Email IRDAI RO Bangalore**: ro-bangalore@irdai.gov.in
3. **Tag ICICI Lombard nodal officer** in IGMS

**IRDAI 30-Day Rule (2026)**: Cashless decision must be communicated within **30 minutes** for emergency, **2 hours** for planned. Denial without written reasons = regulatory violation.

## Reimbursement Route — If Cashless Fails

### When to Switch
- TPA denies after re-review
- Hospital refuses to re-submit
- Emergency at non-network hospital
- Patient discharged before approval

### Reimbursement Checklist

**Documents (Original + 2 Copies)**:
- [ ] Claim form (Part A by patient, Part B by hospital)
- [ ] Original bills + receipts (itemized)
- [ ] Discharge summary (signed by doctor)
- [ ] All investigation reports
- [ ] Pharmacy bills (with doctor prescription)
- [ ] Implant/stent invoices (with batch stickers)
- [ ] Pre-auth denial letter (critical!)
- [ ] Policy schedule + ID proofs
- [ ] Cancelled cheque + bank mandate form

**Timeline**:
- Submit within **30 days** of discharge
- ICICI Lombard acknowledges in **7 days**
- Settlement in **30 days** from complete docs (IRDAI mandate)

### Reimbursement Denial Codes — Different from Cashless

|------|---------|---------|

| **REIM-DOC** | Missing original bills | Get duplicates from hospital |

| **REIM-EXC** | Policy exclusion | Clause interpretation |

## IRDAI 2026 Cashless Regulations — Your Weapons

### Key Provisions (IRDAI/Reg/13/2026)

1. **30-minute emergency decision**: Life-threatening = 30 min max
2. **2-hour planned decision**: Elective = 2 hours max
3. **Written reasons mandatory**: Every denial must state clause + rationale
4. **Hospital duty**: Must assist in document completion
5. **TPA accountability**: 95% cashless approval rate target
6. **Penalty for delay**: 2% p.a. above bank rate on claim amount

### How to Use Them

**In your IGMS complaint**:
> "TPA [Name] violated IRDAI/Reg/13/2026 Clause 4.2 by not communicating decision within 2 hours. Denial letter lacks specific clause reference per Clause 4.5. Request penalty under Clause 8."

## FAQ — ICICI Lombard Cashless

**Q: Hospital says "TPA not responding."**
A: Hospital must escalate to TPA nodal officer. We call both simultaneously.

**Q: Can I move to network hospital after denial?**
A: Yes, but new pre-auth needed. Continuity of care letter from first hospital helps.

**Q: What if policy has co-pay?**
A: Co-pay applies to approved amount. Denial ≠ co-pay issue. Fight denial first.

**Q: Room rent sub-limit exceeded?**
A: If medically justified (ICU, isolation), argue "medical necessity." Get doctor letter.

**Q: How long for reimbursement after cashless fails?**
A: 30 days from complete docs submission. Interest @ 2% above bank rate if delayed.
